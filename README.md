## 🗂️ Repository Structure

Each SQL problem is stored in a separate `.sql` file with a numbered filename.

Examples:

- `001-Employees-Above-50000.sql`
- `008-Students-Marks-60-Or-Less.sql`
- `024-Average-Salary-By-Department.sql`
- `028-Find-Unique-Departments.sql`

This makes it easy to track my progress as I continue learning new SQL concepts.
